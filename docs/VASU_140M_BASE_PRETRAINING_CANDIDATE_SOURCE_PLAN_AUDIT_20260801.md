# VASU-140M Candidate Source Plan Audit — 2026-08-01

The strategy comparison uses repository evidence plus official FineWeb-Edu,
Wikipedia, ODC-By, CC-BY-SA, and GFDL sources. It selects a candidate release
strategy, not an admitted source or executable data build.

The recommendation excludes the original FineWeb 1M source from v1 because its
provider document IDs and URLs are incomplete. It also excludes direct reuse of
all 257-token binaries. The recovered FineWeb-Edu extension is preferred as the
broad primary because all retained source IDs and historical text hashes were
recovered. Wikipedia is capped as a secondary source because it adds factual
coverage but cannot serve as a balanced general corpus alone.

The proposed 90/10 target is conditional on exact post-filter token counts and
never permits replacement sampling. Both sources still require separate
VASU-140M admission packages; FineWeb web-rights interpretation and Wikipedia
attribution/ShareAlike handling remain explicit review gates. No network
acquisition, registry edit, data construction, or model operation occurred.
